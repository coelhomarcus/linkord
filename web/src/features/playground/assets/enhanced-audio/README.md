# Enhanced Audio sounds

The playground's sounds, from [Enhanced Audio](https://modrinth.com/resourcepack/enhanced-audio) (release 7)
by Frawzy (all rights reserved). They are used for now and will be replaced. The files are unchanged
copies of the pack's files of the same path under `assets/minecraft/sounds/`, only those the game plays
(`engine/sounds.ts`):

- `step/`, `dig/` and `block/<material>/`: footsteps, digging, breaking and placing, by what a block is made of;
- `block/chest/`: a chest opening and closing;
- `random/`: picking items up, glass breaking, a new level;
- `liquid/`: splashing into water and swimming;
- `damage/` and `entity/player/attack/`: hits and critical hits.
