# Pixel Perfection textures

Textures from [Pixel Perfection Community Edition](https://github.com/Athemis/PixelPerfectionCE)
(commit 28e38cab), originally by XSSheep and updated by the community, licensed under
[CC BY-SA 4.0](LICENSE.md). Only what Kenui's Default (`../kenuis-default/`) does not draw comes from here;
the files are unchanged copies of the pack's files of the same name:

- `item/coal.png`, `item/charcoal.png`, `item/iron_nugget.png` and `item/lantern.png` (the lantern item's
  picture; the block is Kenui's), from `assets/minecraft/textures/item/` (`inventory/items.ts`);
- `particle/`, from `assets/minecraft/textures/particle/`: the stars of a critical hit, the damage heart and
  the puff a dead player leaves, whose frames a torch's smoke plays too (`engine/particles.ts`).
