# Mandala's GUI

The playground's interface sheets, from [Mandala's GUI - Dark mode](https://modrinth.com/resourcepack/mandalas-gui-dark-mode)
by CesarZorak (all rights reserved). They are used for now and will be replaced. The files are
unchanged copies of the pack's files from `assets/minecraft/textures/gui/`:

- `gui/icons.png` (the hearts, the shanks of food, the air's bubbles and the experience bar) and `gui/widgets.png` (the hotbar), cut by `hud/gui.ts`;
- `container/inventory.png`, `container/crafting_table.png`, `container/furnace.png` and
  `container/generic_54.png` as `gui/inventory.png`, `gui/crafting_table.png`, `gui/furnace.png` and
  `gui/generic_54.png`: the inventory's, a crafting table's, a furnace's and a chest's screens;
- `container/creative_inventory/tab_items.png` and `tabs.png` as `gui/creative_inventory/`: the creative
  chest's screen and its scroll bar.
